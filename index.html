About Me

I learn best by turning ideas into working projects.

Hi, I'm Arun Kumar—a student and self-taught developer from India. My coding journey is a bit unconventional: I build primarily from my Android phone using Termux. By leveraging Python, modern web technologies, and AI-assisted tools, I turn everyday curiosity into practical utilities and creative experiments.

To me, development is an ongoing loop of discovery. Every idea sparks an experiment, every experiment evolves into a working build, and every mistake is a stepping stone. This portfolio is a live documentation of that process.

My core focus is on creating tools that solve real problems by exploring the intersection of code, creativity, and automation. I'm deeply passionate about open-source ecosystems, Linux, and using technology to make life easier.

Currently, I'm expanding my skill set by diving deeper into JavaScript frameworks, advanced Python, and AI-driven development.
